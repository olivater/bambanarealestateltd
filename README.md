# Bambana Real Estate Website

A modern, responsive 5-page corporate website for Bambana Real Estate (Uganda).

## Pages
- **Home** (`index.html`) – Hero, featured properties, why choose us, stats, CTA
- **Properties** (`properties.html`) – Listings & projects
- **About** (`about.html`) – Story, mission/vision/values, team
- **FAQ** (`faq.html`) – Accordion FAQ
- **Contact** (`contact.html`) – Netlify form + contact details with icons

## Tech
- Pure HTML5, CSS3, vanilla JavaScript
- Google Fonts (Playfair Display + Inter)
- Responsive (mobile-first)
- CSS animations & scroll fade-ins
- Netlify Forms for contact form

## Color Palette
- 60% Beige / White: `#F8F6F2` / `#FFFFFF`
- 30% Navy: `#1A2B4C`
- 10% Gold: `#C9A961`

## Deploy to Netlify
1. Drag & drop the `bambana-real-estate` folder to Netlify, or connect a Git repo.
2. The contact form uses `data-netlify="true"` and `name="contact"` — Netlify will detect it automatically.
3. After deploy, test the form. Submissions appear in Netlify → Forms.

## Local Preview
Open `index.html` in a browser, or use a simple server:
```bash
npx serve .
```
